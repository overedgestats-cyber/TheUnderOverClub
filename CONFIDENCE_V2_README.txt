THE UNDER OVER CLUB — CONFIDENCE V2

This upgrade keeps Model Probability separate from Confidence.

Model Probability:
- estimated chance the selection wins

Confidence:
- 35% data quality
- 35% agreement between Poisson and empirical model
- 25% consistency between overall and venue-specific form
- 5% H2H support

Bookmaker Probability:
- binary O/U and BTTS markets are de-vigged when both sides exist
- 1X2 is de-vigged when home/draw/away all exist
- Double Chance fair probability is derived from de-vigged 1X2
- raw 1/odds is used only as a fallback when de-vigging is not possible

Qualification remains:
- confidence >= 75%
- value edge >= +5 percentage points
- data quality >= 65%
- valid odds

This package does NOT store recommendations.
